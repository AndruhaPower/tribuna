# Подкасты, подэтап 1 — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.

**Goal:** Каталог, подписки, прослушивание подкастов (без загрузок).
**Spec:** `docs/superpowers/specs/2026-11-20-podcasts-1-design.md`

## Global Constraints
- D3–D6, D11, D12, D15, D17–D26 (паттерн экрана, модули, Palette/Typography, Lucide-иконки, замеры PNG 780 px = 390 pt, возврат из фона, https-only медиа, только портрет).
- Тесты: `./generate && xcodebuild test -workspace Tribuna.xcworkspace -scheme <Схема> -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max,OS=26.0.1' -derivedDataPath /private/tmp/claude-502/tribuna-dd` — проверять ненулевое число тестов (схема тестов CoreUI — `CoreUITests`).
- Миграции — файлами; на `tribuna_db` применяет пользователь (`supabase db push` с ветки работы).
- Русские комментарии; коммиты на русском с `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. Позиция переживает выход из приложения, смену выпуска и прерывание звонком.
2. Радио после обобщения движка ведёт себя как раньше (все тесты CorePlayback и сценарии D23).
3. Ленты с нестандартными полями (длительность «1234», «12:34», «1:02:03»; без guid; http-аудио) не роняют разбор; http-выпуски отбрасываются.
4. Большие обложки не раздувают память (даунсэмплинг).
5. Счётчики «новых» сходятся между плитками, бейджем и списком.

### Task 1: Каталог, лента, хранилища
Миграция `podcasts` + проверенный начальный список; `Podcast`, `Episode`, протоколы в CoreDomain; `SupabasePodcastsRepository`, `FeedRepository` (RSS + кеш на диске + троттлинг 30 мин), `SubscriptionsStore`, `ListeningProgressStore` в CoreRepositories; `Services.make` расширен. Тесты разбора и хранилищ.

### Task 2: Движок для выпусков
`PlaybackItem`, перемотка/скорость/длительность/позиция в `AudioPlayer`; движок с настоящей паузой для выпусков; сохранение позиции; Now Playing и команды для выпусков; FeatureRadio/FeaturePlayer переведены на `PlaybackItem`. Тесты, радио без регрессий.

### Task 3: Картинки
`ImageLoader`: целевой размер (ImageIO, вне главного потока), стоимость в `NSCache` (`totalCostLimit`), API с размером; существующие гербы/значки без изменений поведения. Тесты.

### Task 4: Вкладка «Подкасты»
`FeaturePodcasts`: координатор, экран вкладки («Подборка» / «Подписки», бейдж), экран подкаста; модели и тесты (новые, бейдж, выбор сегмента, подписка); вёрстка по `4 · Подкасты.png`; подключение вкладки в приложении.

### Task 5: Плеер подкаста и мини-плеер
Вариант плеера по `5 · Плеер.png` (ползунок, −15/+30, скорость, таймер сна, «Поделиться»; без «Скачан»); мини-плеер с прогрессом «18:42 из 34:10». Тесты моделей, вёрстка.

### Task 6: Проверка и документация
Пользователь — `supabase db push`. Симулятор на реальных лентах (подписка, прослушивание, перемотка, скорость, продолжение после перезапуска, радио по-прежнему работает). D27 в `docs/decisions.md`.
