# Подкасты, подэтап 2 (загрузки и офлайн) — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.

**Goal:** Фоновые загрузки выпусков, офлайн-прослушивание, сегмент «Загрузки», Профиль со счётчиками и блоком «Загрузки», кеш каталога.
**Architecture:** Протокол `EpisodeDownloads` в CoreDomain; реализация на фоновой `URLSession` в CoreRepositories, создаётся приложением один раз; плеер берёт локальный файл через замыкание; фичи видят только протокол.
**Spec:** `docs/superpowers/specs/2026-11-20-podcasts-2-design.md`

## Global Constraints
- D3–D6, D11, D12, D15, D17–D29 (паттерн экрана D21, модули, Palette/Typography, Unbounded только для заголовков и цифр профиля — D18, Lucide-иконки, замеры PNG 780 px = 390 pt, возврат из фона, https-only, только портрет).
- Без новых зависимостей.
- Тесты: `./generate && xcodebuild test -workspace Tribuna.xcworkspace -scheme <Схема> -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max,OS=26.0.1' -derivedDataPath /private/tmp/claude-502/tribuna-dd` — проверять ненулевое число тестов (схема CoreUI — `CoreUITests`).
- Русские комментарии; коммиты на русском с `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `Services.make` вызывается в DEBUG-моках несколько раз — фоновую сессию в нём **не** создавать: две сессии с одним идентификатором ломают доставку событий.

## Review Focus
1. Приложение выгружено во время загрузки → при следующем запуске (или пробуждении системой) файл перенесён, запись `downloaded`, «Занято» верно. Тест: `finishMovesFileAndPersists` + `restoresFromIndexAfterRelaunch` (Task 1).
2. Файл удалён/пропал при живой записи → запись исчезает при запуске, «скачан» не показан, плеер играет из сети. Тесты: `reconcileDropsMissingFiles` (Task 1), `playsRemoteWhenNoLocalFile` (Task 2).
3. Повторное «Скачать» / «Скачать» уже скачанного → без дубля и без второй задачи. Тест: `downloadIsIdempotent` (Task 1).
4. Удаление выпуска, который сейчас играет из файла → звук не обрывается до конца сессии AVPlayer; при следующем запуске выпуска — сеть. Принять как поведение, тест `removeWhilePlayingKeepsState` (Task 4, модель плеера: кнопка становится «Скачать»).
5. Сеть пропала, каталога в памяти нет → «Подборка»/«Подписки» из кеша, «Загрузки» без сети. Тест: `catalogFallsBackToCacheOnFailure` (Task 2) и `downloadsSegmentNeedsNoCatalog` (Task 3).

**Interfaces — Produces:**
```swift
// CoreDomain
public enum DownloadState: Sendable, Equatable, Codable { case waiting, downloading(progress: Double), downloaded(bytes: Int64), failed }
public struct DownloadedEpisode: Sendable, Equatable, Codable, Identifiable {
    public var id: EpisodeID { episode.id }
    public let episode: Episode; public let podcast: Podcast; public let addedAt: Date
    public var state: DownloadState
    public var artworkFile: URL?   // локальная обложка; nil — ещё не скачана или не удалась
}
@MainActor public protocol EpisodeDownloads: AnyObject {
    var items: [DownloadedEpisode] { get }                  // новые (addedAt) первыми
    var itemsPublisher: AnyPublisher<[DownloadedEpisode], Never> { get }
    var wifiOnly: Bool { get set }                          // UserDefaults "podcasts.downloads.wifiOnly", по умолчанию true
    func download(_ episode: Episode, podcast: Podcast)      // уже есть (не .failed) — ничего
    func remove(_ id: EpisodeID)                            // отмена идущей или удаление скачанной
    func removeAll()
    func localFile(for id: EpisodeID) -> URL?               // только .downloaded и файл существует
    func usage() -> (bytes: Int64, count: Int)              // только .downloaded
    func availableCapacity() -> Int64?                      // volumeAvailableCapacityForImportantUsage
}
extension EpisodeDownloads { public func item(_ id: EpisodeID) -> DownloadedEpisode? }
// CoreRepositories
public final class BackgroundEpisodeDownloads: NSObject, EpisodeDownloads {
    public static func make(defaults: UserDefaults = .standard) -> BackgroundEpisodeDownloads  // одна на приложение
    public func handleBackgroundEvents(identifier: String, completion: @escaping () -> Void)
}
```

- [ ] **Step 1: Тесты** (`DownloadsIndex` на временной папке; события делегата — через внутренние методы `handleFinished(id:tempFile:mimeType:)`, `handleProgress(id:written:expected:)`, `handleFailure(id:cancelled:)` без настоящей сессии; сессия — за внутренним протоколом с фейком, считающим созданные задачи и их `allowsCellularAccess`):
  - `finishMovesFileAndPersists` — temp-файл перенесён в `Downloads/`, `state == .downloaded(bytes: <размер>)`, новый индекс из той же папки видит запись.
  - `restoresFromIndexAfterRelaunch` — новый объект над той же папкой: записи и состояния на месте; идущая без задачи в сессии → `.failed`.
  - `reconcileDropsMissingFiles` — запись `.downloaded`, файла нет → после загрузки индекса записи нет.
  - `downloadIsIdempotent` — два `download` одного выпуска → одна запись, одна задача; `.failed` → новая задача.
  - `extensionFromURLThenMime` — `…/a.m4a?x=1` → m4a; без расширения + `audio/mpeg` → mp3; `audio/x-m4a` → m4a; иное → mp3.
  - `wifiOnlyRestartsActiveTasks` — смена `wifiOnly` отменяет идущую задачу и создаёт новую с `allowsCellularAccess == !wifiOnly`; `.downloaded` не трогает.
  - `removeAllDeletesFilesAndUsageIsZero`, `failureNotCancellationMarksFailed`, `cancellationRemovesEntry`.
