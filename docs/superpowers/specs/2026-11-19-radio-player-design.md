# Эфир и плеер — проект

Дата: 2026-11-19. Статус: на согласовании.

## Зачем

Вторая половина концепта — «слушать». Нужен экран «Эфир» (макет `docs/design/3 · Эфир.png`), общий движок воспроизведения (D15), мини-плеер над таб-баром на всех вкладках и полноэкранный плеер (макет `docs/design/5 · Плеер.png`, для радио — без перемотки и скорости).

**Цели**
- Каталог станций — своя таблица в Supabase (выбор пользователя, подход A).
- «Эфир»: заголовок, поиск «Станция или жанр», чипы жанров «Спорт / Футбол / Хоккей / Новости», карточка «Сейчас играет», «Подборка редакции».
- Воспроизведение в фоне, на экране блокировки и в Пункте управления (play/pause), пауза при звонке и при отключении наушников.
- Мини-плеер над таб-баром на всех вкладках; тап — полноэкранный плеер.
- Полноэкранный плеер радио: шапка «Радио · <станция>», карточка с волной, название станции, подпись «Россия · 128 кбит/с», большая кнопка play/pause, таймер сна.

**Не цели**
- Название трека из потока (ICY) — не показываем; показываем название станции.
- «Слушать эфир матча» / «Слушать под матч» — следующим шагом (связки матч → станция).
- Подкасты — отдельный этап (движок готовится так, чтобы их добавить).
- Поиск по всему Radio Browser (подход B отклонён).

**Анти-цели**
- В каталоге мёртвые потоки.
- Звук играет, а мини-плеер / экран блокировки показывают другое состояние.
- Волна изображает анализ звука — она декоративная.

## Подходы к каталогу

| | Подход | Итог |
|---|---|---|
| **A** ✅ | Таблица `stations` в Supabase, начальный список отобран из Radio Browser и проверен; поиск и чипы фильтруют список в приложении | Выбран пользователем |
| B | Живой поиск по Radio Browser + подборка | Мёртвые потоки, почти нет русского спорта |

**Права на трансляцию** — вопрос к релизу (договорённости со станциями или только станции, разрешающие ретрансляцию); на код не влияет.

## Как устроено

### Бэкенд
`stations`: `id text` (слаг), `name`, `stream_url`, `homepage`, `country` («Россия»), `bitrate int`, `codec`, `genres text[]` (`sport`, `football`, `hockey`, `news`), `subtitle` («Футбол · репортажи»), `featured_order int` (null — не в подборке), `enabled bool`. RLS: клиенту только `select` включённых. Начальные данные — миграцией; каждый поток перед включением проверен (HTTP 200, аудио-content-type).

### Модули
```
CoreDomain     + Station, StationsRepository, AudioPlayer (протокол), PlaybackState
CoreRepositories + SupabaseStationsRepository
CorePlayback   новый: реализация AudioPlayer — AVPlayer, AVAudioSession(.playback),
               MPNowPlayingInfoCenter, MPRemoteCommandCenter, прерывания и смена
               аудиовыхода, таймер сна. Зависит от CoreDomain.
FeatureRadio   экран «Эфир». Зависит от CoreDomain, CoreUI.
FeaturePlayer  мини-плеер (вью) и полноэкранный плеер. Зависит от CoreDomain, CoreUI.
Tribuna (app)  создаёт один AudioPlayer, кладёт мини-плеер в MainTabBarController над
               таб-баром (D19), открывает полноэкранный плеер по тапу.
```
Фичи не знают друг о друге (D5): «Эфир» запускает станцию через `AudioPlayer`, мини-плеер и плеер подписаны на его состояние.

### AudioPlayer (контракт)
`@MainActor`: `state` + паблишер — `item: Station?`, `status: idle | loading | playing | paused | failed(message)`, `sleepTimerEndsAt: Date?`; методы `play(_ station:)`, `togglePlayPause()`, `stop()`, `setSleepTimer(minutes: Int?)`. Для подкастов позже `item` станет общим «что играет».

### Экраны
- **Эфир** — по макету: заголовок Unbounded, поле поиска (фильтр по названию и жанрам, без учёта регистра), чипы (один выбранный; «Спорт» по умолчанию), карточка «Сейчас играет» показывается, только когда что-то выбрано в плеере, «Подборка редакции» — станции с `featured_order` выбранного жанра; при поиске — все совпадения. Пустой результат — «Ничего не нашлось».
- **Мини-плеер** — по макету «Сегодня»: иконка, название станции, «● В эфире» / «Подключение…» / «Не удалось подключиться», кнопка play/pause. Появляется, когда `item != nil`; вкладкам добавляется отступ снизу на его высоту.
- **Плеер** — модально (лист): «вниз» закрывает, шапка «Радио · <станция>», карточка с волной (анимируется только при `playing`), название, подпись, play/pause, таймер сна (15 / 30 / 60 мин / выключить). Перемотки, скорости, «Скачан», «Поделиться» для радио нет.

## Проверки
- Тесты: фильтрация и порядок «Эфира»; состояние мини-плеера и плеера из `PlaybackState`; машина состояний AudioPlayer на фейковом движке (play → loading → playing, ошибка потока → failed, прерывание → paused, наушники отключены → paused, таймер сна на инжектируемых часах → stop); разбор `stations`.
- Вёрстка по замерам PNG («Эфир», «Плеер», мини-плеер на «Сегодня»).
- В симуляторе на реальном каталоге: станция играет (статус `playing`), мини-плеер на всех вкладках, плеер открывается и закрывается, пауза с мини-плеера. Экран блокировки в симуляторе проверяется ограниченно — отмечаем, что проверено.

## Что решено мной (поправь, если не так)
1. Чип по умолчанию — «Спорт»; один выбранный чип.
2. Карточка «Сейчас играет» скрыта, пока ничего не выбрано.
3. Полноэкранный плеер — модальный лист.
4. Таймер сна: 15 / 30 / 60 минут.
5. Ошибка потока — состояние «Не удалось подключиться» с повтором по play.
