# Карточка матча — проект

Дата: 2026-11-19. Статус: на согласовании.

## Зачем

С «Сегодня» тап по матчу сейчас открывает заглушку. Карточка — второй экран по паттерну D21: подробности матча, закладка, напоминание и турнирная таблица. Макет: `docs/design/2 · Карточка матча.png`.

**Цели**
- Шапка «АПЛ · 12 тур», кнопки «назад» и «поделиться».
- Блок матча: статус (LIVE / время начала / «Завершён» / «Перенесён» / «Отменён»), команды с кружками-аббревиатурами, счёт крупно (Unbounded), подпись «Счёт обновляется с небольшой задержкой» для футбола.
- Кнопки «В закладках» / «В закладки» (общее хранилище закладок с «Сегодня») и «Напомнить».
- Таблица турнира: «# · Команда · И · О», строки обеих команд матча подсвечены.
- Обновление: при открытии, при возврате из фона (D21) и раз в 60 с, пока матч идёт.

**Не цели**
- Блок «Слушать под матч» — нужны связки матч → станция/подкаст (D16) и плеер (D15). Блок скрыт.
- Таблица НХЛ — у НХЛ своя структура (конференции, дивизионы); карточка хоккейного матча пока без таблицы.
- Ссылки на матч (Universal Links) — «Поделиться» отдаёт текст.
- Серверные пуши — напоминание локальное (см. ниже).

**Анти-цели**
- Состояние закладки на карточке и на «Сегодня» расходится.
- Напоминание срабатывает для уже начавшегося или отменённого матча.

## Подходы к напоминанию

| | Подход | Плюсы | Минусы |
|---|---|---|---|
| **A** ✅ | Локальное уведомление `UNUserNotificationCenter` за 15 мин до начала | Работает сразу, без бэкенда, входа и APNs | Не узнает о переносе матча; не синхронизируется между устройствами |
| B | Серверный пуш (Supabase + APNs, как в концепте) | Учтёт перенос, работает на всех устройствах | Нужны вход, токены устройств, ключ APNs, задача на бэкенде — отдельный этап |

Предлагаю **A** сейчас; B — вместе с входом через Apple. Перенос частично закрываем: при каждом открытии приложения напоминания пересверяются с актуальным временем матча (пересоздаются или снимаются).

## Как устроено

- `FeatureMatch` получает `Feature<Имя>.make(dependencies:output:)` по D21 вместо заглушки; на вход — `MatchID`.
- `CoreDomain`: `MatchesRepository.match(id:) async throws -> Match?`; новый `StandingsRepository.standings(competitionCode:) async throws -> [StandingRow]` (`StandingRow`: position, team, played, points); `RemindersStore` (`@MainActor`: `isScheduled(id)`, `toggle(match)`, паблишер).
- `CoreRepositories`: футбол — `matches` по id, `standings` + `teams` по турниру (только `stage`/`group_name` основной таблицы); НХЛ — матч через `score/{date}` по дате из `MatchID`-контекста или `gamecenter/{id}/landing`; `UNUserNotificationCenter`-реализация `RemindersStore`. Разрешение на уведомления спрашивается при первом нажатии «Напомнить»; отказ — сообщение с переходом в Настройки.
- Приложение: `openMatch(MatchID)` с «Сегодня» пушит карточку; заголовок навигации — системный «назад» и кнопка «поделиться» по макету.
- «Поделиться»: `UIActivityViewController` с текстом «Ливерпуль — Арсенал, 2 : 1 · АПЛ, 12 тур».

## Проверки

- Unit-тесты модели карточки: состояния статуса и счёта, подпись задержки только для футбола, подсветка строк команд матча, кнопка «Напомнить» скрыта для начавшегося/завершённого/отменённого матча, обновление только при live, закладка синхронна с хранилищем.
- Unit-тесты репозиториев: разбор таблицы, `match(id:)` для футбола и НХЛ, планирование/снятие напоминания (фейковый центр уведомлений).
- Вёрстка по замерам PNG, как у «Сегодня»; проверка на реальных данных в симуляторе.

## Что решено мной (поправь, если не так)

1. Напоминание — локальное уведомление (подход A).
2. Блок «Слушать под матч» скрыт до радио и плеера.
3. Карточка НХЛ без таблицы.
4. Таблица турнира — полная, с подсветкой обеих команд матча.
5. «Поделиться» — текстом, без ссылки.

## Что остаётся исполнителю

Точные размеры (замер по макету), текст сообщения об отказе в уведомлениях, структура ячеек.
