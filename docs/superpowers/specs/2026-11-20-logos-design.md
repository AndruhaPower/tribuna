# Логотипы команд и турниров — проект

Дата: 2026-11-20. Статус: согласовано в чате (пользователь: «Да, логотипы»).

## Зачем
Пользователь хочет видеть логотипы команд и турниров на «Сегодня» и в карточке матча, в стиле приложения. Ссылки уже лежат в базе: `teams.crest_url` (111, все PNG), `competitions.emblem_url` (6, все PNG). Пересматривает решение D16 «гербы клубов не используем» — по просьбе пользователя.

**Цели**
- Логотип команды в кружке на месте аббревиатуры: «Мои события» на «Сегодня», блок матча в карточке, строки турнирной таблицы (маленький, перед названием).
- Логотип турнира: небольшой значок перед заголовком секции на «Сегодня» и в шапке карточки матча («[лого] АПЛ · 11 тур»).
- Пока картинка грузится или не загрузилась — как сейчас: аббревиатура в кружке / секция без значка.

**Не цели**
- НХЛ — у команд остаются аббревиатуры (логотипы только SVG; UIKit на iOS 16 SVG по ссылке не рисует; библиотеку не подключаем).
- Логотипы станций в «Эфире».
- Строки списка матчей на «Сегодня» (в макете там только названия).

**Анти-цели**
- Новая зависимость ради загрузки картинок.
- Мигание/прыжки при прокрутке и переиспользовании ячеек (картинка от другой команды в чужой ячейке).
- Тёмный герб, невидимый на тёмном фоне.

## Как устроено
- `CoreDomain`: `Team.logoURL: URL?`, `Competition.emblemURL: URL?` (футбол — из базы, НХЛ — nil).
- `CoreRepositories`: в запросах футбола и таблицы добавить `crest_url`/`emblem_url`, маппинг в модели.
- `CoreUI`: `ImageLoader` (общий, `@MainActor`): память — `NSCache`, диск — `URLCache` с увеличенной ёмкостью, один запрос на URL при параллельных обращениях; `RemoteImageView` с отменой при переиспользовании и проверкой «картинка всё ещё для этого URL». `TeamBadgeView` получает `logoURL`: логотип вписан в кружок `Palette.surfaceHigh` с внутренним отступом (≈18 % диаметра), до загрузки — аббревиатура.
- Экраны: состояние (State) несёт URL — контроллер ничего не форматирует (D21).

## Проверки
- Тесты: маппинг URL из строк базы; `ImageLoader` — кеш в памяти и склейка одновременных запросов (фейковая загрузка); состояние экранов несёт URL (футбол) / nil (НХЛ).
- Симулятор на реальных данных: «Сегодня» (секции со значками, «Мои события» с гербами), карточка матча (шапка, блок, таблица). Скриншоты.
- D26 в `docs/decisions.md`: пересмотр D16 по просьбе пользователя, правила показа, НХЛ без логотипов, гербы — товарные знаки (вопрос к релизу).
