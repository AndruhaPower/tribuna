# Обновления 1.1 и 1.2: фичи под тоглами — проработка

Дата: 2026-11-25. Статус: проработано, **не реализуется** до релиза 1.0. Решение пользователя: две небольшие фичи — виджет на домашнем экране (1.1) и проработанный экран профиля (1.2).

## Тоглы: на этапе сборки, не удалённые

- **Почему не удалённый конфиг.** Apple отклоняет «скрытые функции», которые включаются после ревью (правило 2.3.1). Виджет к тому же нельзя спрятать из галереи во время работы приложения. Поэтому фича включается сборкой и проходит ревью в том обновлении, где появилась.
- **Механизм (~10 строк в `Project.swift`).** Переменная `TUIST_FEATURES="widget,profile2"` превращается в условия компиляции `FEATURE_WIDGET` и `FEATURE_PROFILE2` у всех таргетов (`SWIFT_ACTIVE_COMPILATION_CONDITIONS`). Таргет виджета добавляется в проект только при `widget`. Без переменной всё выключено.
- **Как работаем.** Код живёт в `main` под `#if FEATURE_…`, тесты фичи гоняются со своим флагом. Релиз — флаг включён по умолчанию в `Project.swift`. Через одно обновление после релиза `#if` удаляем.

## 1.1 — виджет «Сегодня» (`FEATURE_WIDGET`)

**Что видит человек**
- **Маленький** — ближайший или идущий матч: турнир, команды (аббревиатуры, гербов нет, D34), счёт или время начала, «LIVE».
- **Средний** — до трёх матчей дня: сначала из закладок, затем по времени начала.
- **На экране блокировки** (`accessoryRectangular`, iOS 16) — один матч одной строкой.
- Нажатие на матч открывает его карточку, на пустой виджет — «Сегодня». Матчей нет — «Сегодня матчей нет» и ближайший день с матчами.

**Устройство**
- Таргет `TribunaWidget` (WidgetKit + SwiftUI). Это единственное исключение из D6: виджеты бывают только на SwiftUI. Зависимости — `CoreDomain`, `CoreRepositories`.
- **Матчи.** Расширение само читает `FootballRepository` через Supabase. URL и publishable-ключ переносим из `AppConfig` в `CoreRepositories` или в Info.plist обоих таргетов.
- **Закладки.** Приложение пишет id закладок в общие `UserDefaults(suiteName: "group.com.tribuna.app")` (ключ `widget.bookmarks`) и при каждом изменении вызывает `WidgetCenter.reloadAllTimelines()`. Без входа закладок нет, виджет показывает просто матчи дня.
- **App Group** `group.com.tribuna.app` — платная capability, только в сборке для стора (как в D35).
- **Расписание обновлений.** Записи на моменты начала матчей. Идёт матч — следующее обновление через 5 мин, иначе — к началу ближайшего матча, но не позже чем через 30 мин. iOS даёт примерно 40–70 обновлений в день; счёт в виджете может отставать, и это нормально.
- **Ссылка из виджета.** Своя схема `tribuna://match/<MatchID>` (`CFBundleURLTypes`): домена нет, универсальные ссылки отложены (D35). `SceneDelegate.scene(_:openURLContexts:)` открывает карточку матча тем же путём, что и `-MatchMockData`.
- Подпись football-data остаётся в приложении (D34). Условия требуют её «в приложении», виджет — его часть.

**Тесты.** Чистые функции: выбор матчей для среднего виджета (сначала закладки, затем время, не больше 3) и политика обновления (идёт матч / до начала / нет матчей).

**Оценка.** 1,5–2 дня, плюс макет виджета.

**Как включить.** `TUIST_FEATURES=widget ./generate` — локально и в сборке на ревью; к выпуску 1.1 — `widget` по умолчанию в `Project.swift`. Перед выгрузкой — App Group в Developer-портале для `com.tribuna.app` и расширения.

**Что нового в 1.1 (текст для App Store):**
> Виджет «Сегодня» на домашнем экране и экране блокировки: ближайшие матчи, счёт и статус «в эфире» — без открытия приложения. Матчи из закладок — первыми.

## 1.2 — экран профиля по макету (`FEATURE_PROFILE2`)

Макет `docs/design/6 · Профиль.png`: в 1.0 из него не сделаны «Уведомления», «Турниры в ленте» и «О приложении и источниках данных» (см. «Не цели» в спеке профиля 2026-11-20).

**Уведомления**
- **«Начало событий — за 15 минут, для закладок».** Включено — закладка сама ставит напоминание (`RemindersStore`, D22). Выключено — напоминания по закладкам снимаются, кнопка «Напомнить» в карточке остаётся. Разрешение на уведомления спрашиваем при включении.
- **«Новые выпуски — из моих подписок».** Локальное уведомление из фоновой задачи D35: лента подписки принесла выпуск новее последнего виденного. Серверные пуши и Mindbox для этого не нужны. «Последний виденный» хранится по подкасту в `UserDefaults`.

**Турниры в ленте**
- Экран со списком турниров и переключателями. Выключенные не показываются на «Сегодня» и в виджете.
- Хранится в iCloud KVS с копией в `UserDefaults`, поэтому работает без входа и переезжает на новый iPhone. KVS уже включён и используется для «Только по Wi-Fi» (D38) — добавляется только новый ключ.

**О приложении и источниках данных**
- Версия, политика конфиденциальности, связь с нами.
- Источники и лицензии: football-data.org с подписью, RSS-ленты подкастов с владельцами, радиостанции, шрифт Unbounded (OFL), SnapKit и supabase-swift (MIT).
- Это же помогает на ревью по 5.2: права на контент видны в самом приложении.

**Имя в карточке аккаунта** — можно изменить (`full_name` в user metadata Supabase).

**Тоглы.** Новые секции под `#if FEATURE_PROFILE2`, профиль 1.0 без них не меняется.

**Тесты.** `ProfileFormatter` с новыми секциями; фильтр турниров на «Сегодня»; правило «новый выпуск» (новее последнего виденного, первый запуск ничего не шлёт).

**Оценка.** 2–3 дня.

**Как включить.** `TUIST_FEATURES=profile2 ./generate`; к выпуску 1.2 — `profile2` по умолчанию в `Project.swift`. Обновить политику конфиденциальности: локальные уведомления о новых выпусках.

**Что нового в 1.2 (текст для App Store):**
> Профиль стал удобнее: уведомления о начале матчей из закладок и о новых выпусках ваших подкастов, выбор турниров для ленты «Сегодня» и раздел «О приложении» с источниками данных. Имя в профиле теперь можно изменить.

## Открытые вопросы
- Макет виджета (размеры, LIVE, пустое состояние) — нужен от дизайна.
- Политика конфиденциальности — нужна ссылка на страницу. Её же требует App Store Connect.
- Mindbox (D35): если договор будет к 1.2, «Новые выпуски» можно перевести на серверные пуши. Локальный вариант остаётся запасным.
