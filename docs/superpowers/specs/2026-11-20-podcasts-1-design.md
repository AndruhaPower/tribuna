# Подкасты, подэтап 1 (каталог, подписки, прослушивание) — проект

Дата: 2026-11-20. Статус: на согласовании. Подход A выбран пользователем; загрузки — подэтап 2.

## Зачем
Четвёртая вкладка концепта: болельщик подписывается на спортивные подкасты и слушает выпуски (макет `docs/design/4 · Подкасты.png`), плеер подкаста — `5 · Плеер.png`.

**Цели**
- Каталог подкастов — таблица Supabase (как станции), выпуски — из RSS-лент прямо в приложении с кешем на диске.
- Вкладка «Подкасты»: «Подборка» (каталог, подписаться) и «Подписки» (плитки подписок с «N новых», «Новые выпуски» со «Слушать»). Экран подкаста — список выпусков и «Подписаться».
- Плеер подкаста: позиция, перемотка ползунком, −15 / +30 с, скорость, таймер сна, «Поделиться». Мини-плеер: «Вне игры · 18:42 из 34:10».
- Позиция прослушивания сохраняется; выпуск, дослушанный до конца (≥95 %), считается прослушанным.

**Не цели (подэтап 2 и дальше)**
- Скачивание, офлайн, вкладка «Загрузки», «Только по Wi-Fi», «Занято / Очистить» в профиле, кнопки «Скачать» / «Скачан» — подэтап 2 (сегмент «Загрузки» пока скрыт).
- Пуш о новом выпуске, синхронизация подписок и позиции между устройствами (iCloud / вход) — позже.
- Поиск по подкастам (в макете его нет).

**Анти-цели**
- Позиция теряется при закрытии приложения или смене выпуска.
- Обложка в 3000×3000 грузит память и тормозит прокрутку.
- Плеер радио ломается от обобщения движка.

## Решения
- **Каталог:** `podcasts(id, title, author, feed_url, artwork_url, featured_order, enabled)`, RLS только чтение. Начальный список 10–15 русскоязычных спортивных подкастов из iTunes Search; каждый проверен: лента отдаётся, есть выпуски, аудио и обложка по `https` (иначе ATS).
- **Выпуски:** разбор RSS (`XMLParser`): guid, заголовок, дата, длительность (`itunes:duration` в любом формате), `enclosure` (https), обложка выпуска или подкаста, ссылка. Кеш ленты на диске; обновление при открытии вкладки и возврате из фона не чаще раза в 30 мин на ленту.
- **Подписки, позиция, «прослушано»** — на телефоне (`UserDefaults`/файл), как закладки.
- **«Новый» выпуск** — не начатый и опубликованный не раньше чем за 7 дней до подписки. Бейдж «Подписки N» = сумма новых по подпискам («2 новых», «1 новый», «Всё прослушано»).
- **Движок:** `AudioPlayer` переходит на `PlaybackItem` (`.station` | `.episode`). У выпуска — настоящая пауза, перемотка, скорость (0,75 / 1 / 1,25 / 1,5 / 2), длительность; у станции — как сейчас (пауза = переподключение). Позиция сохраняется каждые 10 с, на паузе и при уходе в фон; при новом запуске выпуска продолжаем с сохранённого места. Экран блокировки для выпуска — время, длительность, −15/+30, скорость.
- **Картинки:** `ImageLoader` получает целевой размер (даунсэмплинг ImageIO вне главного потока) и лимит памяти по стоимости (условие из D26).
- **Экран подкаста** — второй экран фичи → координатор фичи (по D21).
- **Подписки по умолчанию:** открыт «Подписки», если они есть, иначе «Подборка».

## Проверки
- Тесты: разбор RSS (несколько реальных лент-фикстур, форматы длительности, битые элементы), «новые», бейдж, сохранение позиции, движок на фейках (пауза/перемотка/скорость/конец выпуска/продолжение с позиции), радио не сломано.
- Вёрстка по замерам PNG, симулятор на реальных лентах: подписаться, слушать, перемотать, закрыть приложение — продолжить с того же места.
