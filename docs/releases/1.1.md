# Tribuna 1.1 — виджет «Сегодня»

Ветка `feature/widget-today`, флаг `FEATURE_WIDGET`. Спека — [2026-11-25-updates-1.1-1.2-design.md](../superpowers/specs/2026-11-25-updates-1.1-1.2-design.md), решение — D40.

## Что нового (текст для App Store)

> Виджет «Сегодня» на домашнем экране и экране блокировки: ближайшие матчи, счёт и статус «в эфире» — без открытия приложения. Матчи из закладок — первыми.

## Как включить

1. Локально и для проверки: `TUIST_FEATURES=widget ./generate`.
2. К выпуску 1.1: в `Project.swift` поставить `widget` по умолчанию — `Environment.features.getString(default: "widget")`.
3. В Developer-портале команды D53MGF5HR8: App Group `group.com.tribuna.app` для `com.tribuna.app` и `com.tribuna.app.TodayWidget` (автоподпись Xcode создаст сама при первой сборке с флагом).
4. Скриншот виджета — в материалы App Review (`docs/app-review.md`), «Что нового» — в App Store Connect.

## Что в сборке

- Таргет `TribunaWidget` (WidgetKit + SwiftUI): маленький — ближайший или идущий матч, средний — до трёх матчей, на экране блокировки — один матч строкой.
- Матчи — `Services.todayMatches` (Supabase, publishable-ключ); выбор и расписание обновлений — `WidgetPlan` (тесты `WidgetPlanTests`).
- Закладки — приложение пишет в App Group `widget.bookmarks` и перерисовывает виджет при каждом изменении.
- Нажатие — `tribuna://match/<id>` открывает карточку матча, пустой виджет — `tribuna://today`.

## Проверено (симулятор iPhone 17 Pro Max, 2026-11-27)

- Тесты с флагом: 354, зелёные.
- Средний виджет на домашнем экране с реальными матчами дня; ссылка `tribuna://match/football:564857` открывает карточку матча.
- Не проверено: маленький виджет и экран блокировки визуально, расписание обновлений во время live-матча, App Group на устройстве с подписью D53MGF5HR8.
