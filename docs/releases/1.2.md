# Tribuna 1.2 — профиль по макету

Ветка `feature/profile-v2`, флаг `FEATURE_PROFILE2`. Спека — [2026-11-25-updates-1.1-1.2-design.md](../superpowers/specs/2026-11-25-updates-1.1-1.2-design.md), решение — D41.

## Что нового (текст для App Store)

> Профиль стал удобнее: уведомления о начале матчей из закладок и о новых выпусках ваших подкастов, выбор турниров для ленты «Сегодня» и раздел «О приложении» с источниками данных. Имя в профиле теперь можно изменить.

## Как включить

1. Локально и для проверки: `TUIST_FEATURES=profile2 ./generate`.
2. К выпуску 1.2: `profile2` по умолчанию в `Project.swift` (`Environment.features.getString(default: "profile2")`; вместе с виджетом — `"widget,profile2"`).
3. Политика конфиденциальности: добавить локальные уведомления о новых выпусках и хранение настроек в iCloud (`docs/privacy-policy.md`).
4. Скриншот профиля с «Уведомлениями» — в материалы App Review, «Что нового» — в App Store Connect.

## Что в сборке

- «Уведомления»: «Начало событий» — закладка сама ставит напоминание за 15 минут (`BookmarkReminders`), выключение снимает напоминания по закладкам; «Новые выпуски» — локальное уведомление из фонового обновления лент (D35). Включение спрашивает разрешение; отказ — переключатель остаётся выключенным, алерт ведёт в Настройки.
- «Турниры в ленте»: список включённых турниров из Supabase, выключенные не показываются на «Сегодня» (`HiddenCompetitionsMatches`).
- «О приложении и источниках данных»: версия, источники данных, лицензии библиотек, шрифта и иконок.
- Смена имени — нажатием на имя в карточке аккаунта (кружок — фото профиля, D43).
- Настройки — `ProfileSettingsStore`: `UserDefaults` + iCloud KVS, без входа, на всех iPhone с одним Apple ID.

## Проверено (симулятор iPhone 17 Pro Max, 2026-11-27)

- Тесты с флагом: 359, зелёные; без флага: 351.
- Профиль с «Уведомлениями» и подвалом по макету; «Турниры в ленте» с турнирами из Supabase; «О приложении».
- Не проверено: системный запрос уведомлений из Профиля, приход уведомления о новом выпуске (нужно фоновое обновление на устройстве), синхронизация настроек между двумя iPhone, смена имени на настоящем аккаунте.
