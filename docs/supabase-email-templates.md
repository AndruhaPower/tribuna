# Письма Supabase Auth для Трибуны

Вход по почте и паролю (D31): регистрация и сброс пароля подтверждаются **6-значным кодом** из письма, без ссылок.

## Настройки (Supabase → Authentication)
- **Sign In / Providers → Email**: включён, «Confirm email» — включено, минимальная длина пароля — 8.
- **Email Templates** — в двух шаблонах должен быть код `{{ .Token }}`.
- **SMTP Settings**: встроенная отправка Supabase — несколько писем в час на проект, только для разработки. До выпуска подключить свой SMTP.

## Confirm signup
Тема: `Код для Трибуны`

```html
<p>Ваш код подтверждения: <strong>{{ .Token }}</strong></p>
<p>Введите его в приложении. Код действует 1 час.</p>
```

## Reset password
Тема: `Сброс пароля в Трибуне`

```html
<p>Код для сброса пароля: <strong>{{ .Token }}</strong></p>
<p>Если вы не запрашивали сброс, просто проигнорируйте письмо.</p>
```
