# Tribuna

Спорт, который слушают. iOS-приложение, в котором болельщик следит за счётом своих команд и тут же слушает спортивное радио и подкасты, не переключаясь между сервисами.

### Поставить на свой iPhone

1. Xcode → Settings → Accounts: войти своим Apple ID (бесплатный подойдёт).
2. iPhone подключить кабелем, «Доверять этому компьютеру», включить «Настройки → Конфиденциальность и безопасность → Режим разработчика».
3. Запустить:

```bash
./install-iphone
```

Если в связке ключей несколько команд, скрипт их перечислит; тогда `TEAM=<Team ID> ./install-iphone`. С бесплатным Apple ID приложение работает 7 дней, потом скрипт запускается снова. Первый запуск на телефоне: «Настройки → Основные → VPN и управление устройством» → доверять разработчика.

## Возможности MVP

| Раздел | Что делает пользователь |
|---|---|
| Сегодня | Видит футбольные матчи (топ-лиги Европы, ЛЧ) по дням: счёт, статус, таблицы |
| Закладки | Сохраняет матчи и получает напоминание за 15 минут до начала |
| Эфир | Слушает спортивное радио в фоне и на экране блокировки |
| Подкасты | Подписывается, скачивает выпуски, слушает офлайн |
| Профиль | Входит по email; без входа приложение тоже работает |

Возможности iOS: фоновое аудио, фоновые загрузки выпусков, фоновое обновление лент подписок, локальные напоминания, iCloud KVS (настройка «Только по Wi-Fi» на всех iPhone). Заведены и включаются правкой в `Project.swift` (D38): пуши и события Mindbox — по endpoint, вход через Apple — флагом `signInWithApple`.

## Источники данных

| API | Что берём | Доступ |
|---|---|---|
| [football-data.org](https://www.football-data.org) | Матчи, счёт, таблицы: 12 турниров, включая АПЛ и ЛЧ | Бесплатный ключ, ~10 запросов/мин |
| Радиопотоки (8 российских станций, каталог в Supabase) | Прямые https-потоки | Открытые потоки вещателей |
| RSS-ленты подкастов (podster.fm, mave.digital) | Русские подкасты, выпуски, mp3, обложки из самих лент | Без ключа |
| Supabase (`tribuna_db`) | Каталоги матчей/станций/подкастов, профили, закладки, подписки, позиция | Свой бэкенд |

Ограничения: футбольный счёт приходит с задержкой, названия команд переводим сами.

Ключ football-data.org не должен попадать в приложение: лимит общий на ключ, поэтому футбольные данные отдаёт бэкенд.

## Быстрый старт

Нужны Xcode 26 и [mise](https://mise.jdx.dev). Tuist ставится сам, версия закреплена в `mise.toml`.

```bash
./generate
open Tribuna.xcworkspace
```

`.xcodeproj` и `.xcworkspace` генерируются и в git не хранятся.

```

docs/design/            Макеты MVP (PNG, @2x)
TRIBUNA.pdf             Концепт MVP
tribuna_api_check.py    Проверка бесплатных API

```

## Архитектура

UIKit + SnapKit, iOS 16+, Swift 6, Tuist, модуль на каждую фичу. Подробности и причины — в [docs/decisions.md](docs/decisions.md).
